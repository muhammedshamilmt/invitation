# Nikah Invitation Landing Page

A static, animated Nikah invitation website inspired by the provided watercolor reference. The page includes the hero invitation, formal family invitation note, ceremony details, story, venue RSVP section, and closing Qur'an quote. The Gallery section has intentionally been omitted.

## Preview

Open `http://127.0.0.1:4173` while the local server is running.

To run it again:

```bash
python3 -m http.server 4173
```
